MICROSOFT FABRIC - RÉFÉRENTIEL DES PARAMÈTRES D'ADMINISTRATION
Rodrigue YENGO - ADRCHIA365 - ARCHIALEARN  - DATA & AI FRANCE
Date de préparation : 08/08/2026

Objet
Ce document présente les paramètres de tenant visibles dans l'administration Microsoft Fabric fournis dans la source, avec leur état observé, une description fonctionnelle et un cas d'utilisation type.

Important
Les états Activé ou Désactivé correspondent à l'état de notre Tenant de test et peuvent différer d'un autre tenant. Les descriptions s'appuient sur les intitulés du fichier et sur l index Microsoft Learn des tenant settings consulté le 08/08/2026. Pour les fonctions en préversion, une validation sécurité, conformité et exploitation'est recommandée avant généralisation.

Lecture des états
Activé pour toute l'organisation : fonctionnalité disponible pour tous les utilisateurs éligibles.
Désactivé pour toute l'organisation : fonctionnalité bloquée au niveau du tenant.
Activé pour un sous-ensemble de l'organisation : fonctionnalité limitée à des groupes ou populations définis.
