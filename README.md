# Microsoft Data Day 2026

Dépôt des supports de formation (slides, code source, notebooks) pour les sessions **Data Day**, organisées dans le cadre du [**Data & AI France Study Group**](https://data-day.archifridays.com/).

## Contexte

Les **Data Days** sont des sessions de formation dédiées aux certifications Microsoft Data & AI. Elles permettent aux participants de renforcer leurs compétences sur Azure, Power BI, Microsoft Fabric et les solutions data/IA, en s’appuyant sur le programme officiel Microsoft.

Plateforme de l’événement : **[data-day.archifridays.com](https://data-day.archifridays.com/)**

Sur le site, vous retrouverez notamment :

- le catalogue des **formations** et le détail de chaque parcours ;
- les **prochaines sessions** (en ligne / visio) ;
- les **programmes PDF** téléchargeables ;
- les informations sur les formateurs et les inscriptions.

Ce dépôt GitHub complète le site en centralisant les **ressources partagées par les formateurs** pour chaque édition.
